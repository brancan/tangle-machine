Tangle Machine Drawings made with code

An instruction is the work

Every piece in this gallery is a short set of rules written as code. Your browser is the hand that carries them out. Hence the name: a machine that makes tangles out of ideas.

“The idea becomes a machine that makes the art.” Sol LeWitt, Paragraphs on Conceptual Art, Artforum, Summer 1967

Manifesto

  1. The code is the instruction, not the picture. A drawing here is a function: lines, distances, angles, decided before anything is drawn. What you see is one execution of it. Change a value and you get another, equally valid.
  2. The rule generates the variety. A few primitives and simple arithmetic make every piece. Repetition with variation is not a limitation of the system; it is its subject.
  3. The hand is computed. Wobble, jitter, pressure and roughness are parameters. The same hand seed always draws the same way; a new seed is a new draftsman working from the same instruction.
  4. You execute the work. Moving a slider or rewriting a line of code is carrying out the instruction. Share the link and someone else can carry it out exactly as you did, or differently.

Wall drawings, in code

Sol LeWitt’s wall drawings exist as written instructions. Draftsmen execute them on a wall, and every installation differs a little because hands differ. This gallery follows the same system:
